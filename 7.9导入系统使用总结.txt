## 🎯 核心功能

### 1. 批量文件导入
- **文件数量**: 20个CSV文件
- **文件命名**: `7.9数据汇总表-utf8_part1.csv` 到 `part20.csv`
- **文件位置**: `/mnt/aidrive/`
- **总数据量**: 约540KB (预计6,700+条记录)
- **导入方式**: 逐个文件顺序导入

### 2. 智能分块策略
根据文件大小动态调整分块大小：
- 超大文件 (>100K行): 100行/块
- 大文件 (>50K行): 120行/块
- 中型文件 (>10K行): 150行/块
- 小文件 (>1K行): 200行/块
- 微型文件 (≤1K行): 300行/块

### 3. 断点续传
- **进度保存**: 每3个分块保存一次
- **进度文件**: `7_9_import_progress.json`
- **恢复能力**: 中断后可从上次位置继续
- **自动清理**: 成功完成后自动删除进度文件

### 4. 后台运行
- **运行方式**: nohup后台执行
- **不阻塞终端**: 可以关闭终端，进程继续运行
- **日志持久化**: 所有输出保存到日志文件
- **进程监控**: 提供实时进度查看工具

### 5. 详细日志记录
- **时间戳**: 每条日志带时间戳
- **日志级别**: INFO、WARN、ERROR、SUCCESS
- **双重输出**: 控制台 + 文件
- **日志文件**: `7_9_import.log`

### 6. 实时统计
- **统计文件**: `7_9_import_stats.json`
- **更新频率**: 实时更新
- **统计内容**: 
  - 文件进度
  - 分块进度
  - 导入记录数
  - 失败次数
  - 预估剩余时间

## ⚙️ 技术特性

### 1. 6位小数价格精度
```javascript
price: parseFloat(row.price) // 自动保留6位小数
```

### 2. 登录Token双格式支持
```javascript
// 支持两种API响应格式
const token = data.token || (data.data && data.data.token);
```

### 3. 自动重试机制
- **最大重试**: 3次
- **重试间隔**: 递增延迟
- **失败处理**: 记录失败块，继续处理

### 4. 延迟控制
- **分块间延迟**: 600ms (防止服务器压力)
- **文件间延迟**: 2000ms (确保稳定性)

### 5. 内存优化
- **流式读取**: 按行读取CSV，不全部加载到内存
- **分块处理**: 小批量提交，控制内存使用
- **及时释放**: 处理完立即释放引用

## 🚨 故障排查

### 问题1: 进程无响应
**症状**: 长时间无日志更新

**排查步骤**:
```bash
# 1. 检查进程是否存在
ps aux | grep import_7_9_batch.mjs

# 2. 查看最新日志
tail -50 7_9_import.log

# 3. 检查网络连接
curl -I https://webapp-csv-import.pages.dev

# 4. 如果进程卡死，重启
pkill -f import_7_9_batch.mjs
./start_7_9_import.sh
```

### 问题2: Token过期
**症状**: 日志显示401未授权错误

**解决方案**:
```bash
# 删除进度文件，重新登录
rm -f 7_9_import_progress.json
node import_7_9_batch.mjs
```

### 问题3: AI Drive访问慢
**症状**: 文件读取非常慢

**排查步骤**:
```bash
# 测试文件访问速度
time head -100 /mnt/aidrive/7.9数据汇总表-utf8_part1.csv

# 如果超过5秒，考虑:
# 1. 等待AI Drive响应恢复
# 2. 减小分块大小
# 3. 增加分块间延迟
```

### 问题4: 内存不足
**症状**: 进程被系统kill

**解决方案**:
```bash
# 查看内存使用
free -h

# 修改脚本减小分块大小
# 或者重启系统释放内存
```
